## 一、`writingBands.js` — 学段与提问红线

```js
BANDS = [mid(3-4), high(5-6)]                  // 只覆盖 3-6 年级
isReaderQuestion(question, sentence)           // 提问红线（见下）
```

**为什么按年级而不按学段带**：学段带是 3-4 / 5-6，而课标的分水岭在三年级。
三年级落在低段里，所以只选段定不了行为，必须选到年级。
这也是入口要选到年级而不是只选学段的原因。

> 2026-11-01：原先这里还有 `PICK_WORDS_FROM_GRADE` / `getBandByGrade` /
> `getBandById` / `shouldPickWords` 四个导出，随"亮好词"这个交互一起下架后
> 成了死代码，已删。年级分叉现在只在拆解 prompt 里（`buildAnalyzerPrompt`）。

### `isReaderQuestion` — 提问红线

来源是管建刚的"号脉"论证：没看到学生写出的东西就指导，一切指导都是假想。

```js
// 合格
A. 引用了孩子句子里的实词      "你写到'粗糙'——摸起来什么感觉？"
B. 读者陈述自己的阅读状态      "读到这里我想知道后来呢"

// 不合格
C. 替孩子决定写什么            "下一句写阳光落在哪儿"
C. 句型填空                    "它______得像______"
```

规则版只能做模式匹配，很粗。

**它现在不是运行时兜底，是评测里的确定性判据。** 2026-11-01 查证：
这个函数曾经一个调用方都没有（`TaskDock` 的注释写着"由服务端
isReaderQuestion 兜底"，但服务端并不 import 它）。真正的保证写在
`READER` prompt 里（"不改他的句子，不告诉他下一句该写什么"、
"绝不要问回头确认的问题"）。

当时考虑过把它接成读者回复的后置校验，**否掉了**：读者回应是整个产品
唯一的动机引擎，而一条模式匹配命中就丢掉整封回信，代价是确定的孩子什么都收不到。
按决策 39 的原则——会抖的判据比没有更糟。所以它活下来的方式是
`eval/cases/offline.js` 的 `redline-001`：拿它自己的三类例子锁住判据不漂移，
**不在运行时拦任何东西**。

## 二、`lib/moveBook.js` — 招式收藏册

不在 `data/` 下但是数据层的一员，所以补在这里。

- 键是 `essayId::moveId::from` 三要素复合键，**必须带 essayId**——
  招式 id 是 `m1/m2/m3` 按次生成的，只比 moveId 会让别篇同一序号冒充自己收过的
- 三种来源：`essay` 从范文学来的招 / `own` 自己用上的句 /
  `spotted` 自己看出来的招（第三类是 2026-10-31 加的，articulation 的产物）
- 三个计数各有驱动：`countLearnedMoves` 和 `countOwnEssays` **合取**驱动支架撤除
  （判据在 `server/src/agent/fading.js`），`favouriteMove` 驱动册子里
  "你最常用的一招"。新增计数前先问这个数驱动什么
- **头衔也用 `countOwnEssays`**（`titleFor`），和 fading 是同一个数，别再另算一套
- `own` 条目带 `topic`，`countGenres` 靠它算"在几种文体里写过"。
  粘贴的范文没有类型，那种篇目不计；旧数据没这个字段时返回 0，
  调用方据此不显示那一行，**不显示成"0 种"**
- `ownSentencesByMove` 驱动证据墙：按招式名分组，最近用过的在前，
  只收有 `mySentence` 的条目（防脏数据）

## 三、`lib/letterStore.js` — 读者的回信

不在 `data/` 下但是数据层的一员。

- 键 `fw.letters`，上限 **60 封**，超出丢最旧的。不设上限的话，
  一个用得很久的孩子会让数组无限增长，而每次读回来都要整个 `JSON.parse`
- 每条：`id / at / moveName / essayTitle / mySentence / reply / degraded`。
  **存本机，不过服务端**——产品立场是不收集身份，也不把孩子的文字传出本机
- 为什么需要存：回信放大镜收回之后 dock 里不留信纸（决策 61），
  那么"收回"就得有个地方能翻回去看，否则等于"再也找不到"。顶栏那个回信入口读的就是这里
- 和册子的分工：册子存**孩子自己的产出**，这里存**读者对他说的话**
  以及引出这封信的那一句

**信纸横线的两个变量**（决策 62/63，都在 `LetterModal.css`）：
`--letter-line` 与 `--letter-size` 必须同步改；横线画在正文 `<p>` 自己身上，
不画在卡片上——卡片有 padding，画在卡片上每行都压在两条线中间。

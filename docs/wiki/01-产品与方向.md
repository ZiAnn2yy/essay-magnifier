# 01 · 产品与方向

## 一、产品是什么

一个面向**小学 1-6 年级**的语文作文学伴。进入页面选年级，共六个年级。

底层逻辑是**两根支柱**，缺一根就不成立：

| | 做什么 | 解决什么 |
|---|---|---|
| **引导写作** | 孩子一句一句写。每写完一句，有个"读者"回应他，那句被放大成胶卷里的一格 | 给孩子写的路径，也让过程可见 |
| **激励写作** | 写完整理成一部"小电影"，能「放给他们看」——绘本 / 动画 / 漫画 | 给孩子写的动力——"我写的东西变成了一个作品" |

**两根的咬合点**：成果的丰富程度取决于作文写得具体不具体。想做出好绘本，
和想写好作文，变成同一件事。

---

## 二、为什么分成两个页面

2026-10-29 用户明确要求拆成两个可跳转的页面：

- **页面一 · 引导写**（已建，即胶卷工作台）
- **页面二 · 作文变作品**（未建）

拆开有三个实在的好处：

1. **第二页能吃到"纸上写的作文"**。孩子在本子上写完好作文，只想要个绘本——
   现在这条路是堵的，激励只能通过引导流程产生。拆开后激励不再依赖引导完成。
2. **第一页变纯了**。不用一边被"放给他们看"诱惑，一边想这句怎么写。
3. **多模态的依赖被关进笼子里**。第二页需要生成能力，第一页完全不需要。
   即使多模态最后没接上，第一页仍是完整产品。

**页面二的上传形式（已定）**：粘贴文本 + 拍照上传。拍照走
「OCR 出草稿 → 落进可编辑输入框让人改 → 再用改后的文本生成」——
机器出草稿，人确认，才成为一格。OCR 当起点不当结论。

## 三、产品脊柱：荣维东的交际语境写作

**这是本产品最重要的一个决定，2026-10-29 定。**

荣维东的界定：写作是作者在特定语境中进行的表达和交流活动。
写作动机来自内在的表达需要，以达成交际功能为宗旨。

**为什么它比管建刚的"作后讲评"更适合做脊柱：**

管建刚反对作前指导的理由是"没号脉就开药"——没看到学生写出的东西就指导，
一切指导都是假想。他的分析单位是**整篇作文**，因此把一切干预推到写完以后。

但产品是 1 对 1 的对话方，**没有课堂的约束**——它可以看着孩子刚写下的
真实句子当场回应。所以管建刚反对的"作前指导"，在产品里的对应物不是
"即时回应"，而是**预判**。

**划出来的线**（这条线是产品的提问红线）：

| | 例子 | 判定 |
|---|---|---|
| 读者在回应 | "读到这里我想知道后来呢" | ✅ 合格 |
| 接着孩子写的内容问 | "你写到'粗糙'——摸起来什么感觉？" | ✅ 合格 |
| 替孩子决定写什么 | "下一句写阳光落在哪儿" | ❌ 不合格 |

管建刚在这里是**约束**（不能预判），不是理论依据。
依据是荣维东（写作是交流）。

**这个决定换来的最大好处**：第二根支柱（变成绘本放给他们看）正好是
荣维东说的"真实读者"的落地。两根支柱因此不是并排，是一根给另一根提供依据。

## 四、核心交互：胶卷

一句一格，连成一条带子。

- **大银幕**：当前这一句被放大成"画面"。孩子的句子是绝对主角
  （幼圆 + 0.7px 描边，66px 起步），界面 chrome 全部让位
- **胶卷**：写完的句子一格一格排下去，空格用虚线画出来吊胃口
- **底部**：读者的回应 + 孩子写这一句 + 「放给他们看！」
- **加载框**：透明、覆盖整块问答区，四步「读你的句子 → 挑能变成画面的词
  → 想该问你什么 → 想好了」

胶卷的形态对应何捷的**百字作文**：每天一句、句句可见、越攒越多。
这是把一句教学实践数字化，不是凭空发明的交互。

### 修改是核心，不是附属

课标把"修改自己的习作，并主动与他人交换修改"放在表达与交流的**核心位置**。
所以胶卷**必须能改**，而且**改前改后都留着**——"我改了什么"要看得见。
（这一点是 2026-10-29 才认识到的，之前只能追加不能改，和课标是顶着的。）

## 五、学段分叉（按课标，不是按感觉）

产品分两个学段带（1-3 / 4-6），但**行为开关按年级**，因为课标的分水岭在三年级：

| 年级 | 课标落点 | 产品动作 |
|---|---|---|
| **1-2** | 对写话有兴趣；**乐于运用**阅读和生活中学到的词语 | **不亮任何词**。开场是一句纯粹的庆祝 |
| **3-4** | **有新鲜感的词句**（课标原词，就出现在这一段） | 这里才开始亮好词 |
| **5-6** | 自我表达和与人交流；**修改自己的习作** | 亮词 + 连到修改 + 读者意识 |

**低段为什么坚决不亮好词**：教研材料明确指出"乐于运用词语并非要求本学段的
学生做到精准、灵活和巧妙地运用词语，而是要求学生树立起运用词语的意识"。
高亮"好词"无论怎么定义"好"，都在传递"有些词比另一些词更值得被看见"——
这是质量标准前置。有一线教师文章直接以《毁掉孩子写作灵气的往往是"好词好句"》
为题。

## 六、激励方向：多模态的两条路

| 路径 | 状态 | 说明 |
|---|---|---|
| **代码渲染** | 现在就能做，确定可用 | SVG + CSS 动效 + 排版做绘本分格和逐格动画 |
| **API 生成** | 待正确 Key | 作为增强层接入，不改变产品成立 |

**三个视觉方向全部不押注生图/生视频 API**——这是刻意的风险控制。
2026-10-29 探测 Kimi：用户提供的 Key 对 Moonshot 返回 401（格式不像
Moonshot 的 `sk-` 系），且 `/videos/generations`、`/audio/speech` 等路径
返回 404 url.not_found。**结论：探不出来，但不阻塞。**
探测脚本留在 `server/scripts/probe-kimi.js`，拿到正确 Key 两分钟能重跑。

## 七、视觉方向：作品胶卷

三套方向由 `oil-ui` skill 出同屏对比，用户选定**方向 2 · 作品胶卷**。
第一轮的成人手工美学（活版纸墨/分镜工作台/粉笔黑板）被用户判定
"一点都不吸引小朋友"，已否决——教训见
[`kids-design-adult-drift`]：**"不低幼"是约束，"有童趣"是目标，两件事**。

配色（不再凭感觉改）：

```
--sky    #BFE9FF   天蓝底。孩子的作业纸不该是白的
--ink    #17384D   墨蓝，压在天蓝上不脏
--orange #FF6B35   主强调
--yellow #FFD23F   荧光笔、当前格
--pink   #FF5D8F   次强调
```

字体的结论是本机实测出来的，不是猜的：
**幼圆 + `-webkit-text-stroke: 0.7px`**。
幼圆是唯一可用的圆体但只有 regular 一档；微软雅黑 Bold 有真粗，
但笔画太粗会把后面的黄色荧光笔压得看不见。0.7px 是唯一两者都保住的档位
（1.4px 笔画糊在一起，0.6px 偏软）。

## 八、语音输入

**立场**：语音的价值不是"省力"，是让"说的话"和"写下来的话"之间的差距变得可见
（叶圣陶：把口头语言和书面语言连在一起说，就叫语文）。所以语音转写完应该
让孩子看见差别，而不是悄悄替他写好。

**撤除判据**（不用年级一刀切）：孩子已能在没有语音转写的情况下独立产出
完整的书面表达。可操作的组合判据是——**连续若干次写作中主动不用语音，
且产出达到"别人能看懂"的水平**，此时撤掉默认启动、保留可选入口。
撤支架的本意是让它不再站在孩子和任务之间，不是让它消失。

**技术**：Web Speech API（`webkitSpeechRecognition`），Chromium 内核自带，
零依赖零成本。Firefox 不支持，需优雅降级。
**麦克风权限要求 HTTPS 或 localhost**——部署到京东云必须是 HTTPS，
否则浏览器直接禁掉麦克风。这条要进部署检查项。

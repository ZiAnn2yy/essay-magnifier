## 一、决策日志

### 2026-10-29 · 范文放大镜（当前方向）

| # | 决定 | 理由 | 别怎么改 |
|---|---|---|---|
| 1 | **产品整体转向**：作文学伴 → 范文放大镜（拆解范文 → 用一招写自己的） | 用户方给的方向 | 别按旧的双支柱理解 |
| 2 | **学段收窄为小学 3-6** | 1-2 年级识字量读不完一篇范文，课标第一学段要的是"乐于运用词语"不是篇章质量 | 别顺手把低段加回来 |
| 3 | **闭环是"用一招写自己的"** | 不是逐段仿写、不是看懂就行 | 别退成阅读工具 |
| 4 | **新脊柱 = 王荣生"例文"说 + 布鲁纳支架式教学** | 原脊柱（荣维东交际语境写作）回答不了"它怎么教会写作"。荣维东降级为阶段三读者身份的约束 | 别试图把管建刚缝回来 |
| 5 | **新红线只有一条：教方法，不给内容** | AI 给招式不给句子，不许句型填空 | 别为了推进剧情放宽 |
| 6 | **代码编排的 agent，不做自主工具调用** | 实测推理模型与 `tool_choice: specified` 不兼容。检索/核对/重试全由代码定，模型只生成 | 别改回 tool_choice |
| 7 | **引用必须逐字出自原文，服务端机械校验** | 把规范§五"不允许编造"变成可断言的闸门。`isValidAnalysis` 返回**具体拒绝原因**而不是布尔 | 别改回布尔，自纠错要靠原因 |
| 8 | **降级不编造** | 模型不可用时只做确定性切段 + 原文还回，`moves: []`，标 degraded | 别让规则引擎凑招式 |
| 9 | **读者人格必须独立**（`agent/reader.js`） | 复用学伴人格实测会回一篇带编号的写作课。2026-10-29 又重写一次：原指令"引用原话说你看见什么"把它教成了逐句镜像 + 阅读理解题 | 别合并回 buildSystemPrompt |
| 10 | **读者回复三步有序**：先表态 → 挑一处说感受 → 问能引出更多写作的问题 | 空夸和冷漠都是失败。明确禁止"是不是/就是指"这类回头确认 | 别改回"复述原文"式指令 |
| 11 | **教学设计知识库每张卡带 `verified` 标记** | 用户提供的研究资料是二手转述，全部标 `false`，渲染时带"未核对原著，引用时需注明" | 别偷偷改成 true |
| 12 | **动效常开，不跟随系统偏好** | 动效是这个产品的内容不是装饰。做过听系统的开关，用户要求删掉 | `html.motion-off` CSS 留着当退路，别删 |
| 13 | **范文分年级动态加载** | 一篇 1.5-3KB，一百篇全静态 import 会让主包背上几百 KB。分片后只在选中那个年级时下载 | 别改回静态 import |
| 14 | **范文全部自撰，不抄教材课文** | 教材编排本身有版权、现当代作者多在保护期内，而交付物要公开上传到魔搭。界面上标"示例范文" | 别为凑数量抄课文 |
| 15 | **访问门槛是一个共享密码，不是管理员账号** | 产品没有可管理的东西，且立场是不收集身份。官方提交要求里明确要"账号密码" | 别建后台 |
| 16 | **密码不进代码** | `xy2005..` 被否：像姓名缩写加出生年，而 git 历史属于作品内容 | 只走 env |
| 17 | **节拍像游戏开局**：开始屏只有一个大按钮 | 第一眼看到表格或说明，孩子就认定"这是作业" | 别加表单 |
| 18 | **跑马灯 40 秒** | 38s 看不出在动、24s 一句没读完就过去。40s 约 43px/s，比阅读速度略慢 | 别再反复调 |
| 19 | **删掉已无调用方的对话链路**（chat/kernel/tools/memory 六文件） | 新产品三个阶段都不需要对话。原 `online-001/002` 测它，其中"不许直接给答案"在 temperature=1 下会漂移——测死代码还漂移 | 别把 kernel 找回来 |

## 五、已知限制（对外表述要注意）

- **多模态是代码渲染，不是 AI 生成**。对外说"画面由排版、SVG 材质滤镜和浏览器能力生成"，
  **不要写"AI 生成动画/绘本"**——那是虚假宣传，评委一问就穿
- **OCR/拍照本期未接**（Kimi 生图 403、OCR 端点不存在），不假装有
- **会话状态不跨部署保留**，对外说"容器生命周期内持久化"，不要说"永久保存"
- **内置范文全部是示例范文**，不得冒充教材范文或学生真作
- **知识库条目是二手转述**，`verified:false`，引用时要注明未核对原著

## 三十秒版本

**产品**：**范文放大镜**——面向小学 3-6 年级的语文作文工具。
AI 拆解一篇优秀范文，把"这一句好在哪里"变成孩子能拿走就用的一招；
孩子用这一招写一句自己的，然后有一个"读者"回应他。

节拍像游戏开局，不像表单：

```
开始 → 选年级 → 选范文 → 拆解 → 用一招写自己的
```

**脊柱理论**：王荣生"例文"说 + 布鲁纳支架式教学。范文是教写作的样例，
拆解它是为了让学生获得**可迁移的写作知识**；产品的支架（直接标好的那几招）
必须**逐步变薄**，否则就是新型句型填空。
荣维东的交际语境写作**降级**为阶段三"读者身份"的约束；
管建刚的"反对作前指导"**只是约束不是依据**（翻译成产品语言是"不许预判"）。

**两条工作线：引导与激励**（2026-10-31 用户定的深入方向，实证依据见 `07`）。

- **引导**：招式卡（给支架）→ `challenge`（说清楚：你自己看这是哪一招）
  → 合取撤除（学过几招 **且** 在几篇里用出来过，才撤）
- **激励**：册子（三种来源：范文学来的 / 自己用上的 / 自己看出来的）
  → 头衔 → 读者来信。**是证据不是奖励，不加积分星级连击排行榜**

**技术栈**：React + Vite（不用 TypeScript）+ Node/Express + StepFun（OpenAI 兼容）
+ 魔搭创空间。不用 TypeScript，不引新技术栈。

**三条红线**（违反即取消资格，优先级高于一切）：
1. 作品内容零个人信息（学校/姓名/指导教师）——含代码注释、README、
   `package.json` 的 `author` 字段
2. API Key 不下前端
3. 11-10 24:00 截止，11-07 冻结新功能

## 快速开始

```bash
# 前端（含 mock 数据，不需要后端就能看）
cd client
npm ci
npm run dev          # http://localhost:5173

# 深链：跳过选年级直接进工作台（录屏用）
# http://localhost:5173/?grade=5
# 直接开到某一篇的拆解
# http://localhost:5173/?grade=5&essay=<id>

# 后端（端口 3010，3000 被别的服务占了）
cd server
npm ci
cp .env.example .env # 填 LLM_API_URL / LLM_API_KEY / LLM_MODEL / ACCESS_CODE
npm start

# 前端连后端 dev
cd client && VITE_API_TARGET=http://localhost:3010 npm run dev
```

**没 Key 也能起**：内置范文命中预处理、`/api/v3/reader` 返回降级话术。

```bash
# 评测（31 条，其中在线 2 条需要 Key，其余无 Key 可跑）
cd server && node --no-warnings eval/run.js

# 册子检索层单测（期望 16/16）
cd client && node --no-warnings scripts/test-movebook.mjs

# 穷尽验证 79 篇（需先起服务）
node --no-warnings server/scripts/verify-all-essays.mjs 3041

# 打出魔搭上传文件夹
node --no-warnings scripts/pack-modelscope.mjs

# 提交前必跑
bash scripts/check-secrets.sh
```

## 三十秒版本

**产品**：一个面向小学 1-6 年级的语文作文学伴，两根支柱——

1. **引导写作**：孩子一句一句写，每写完一句，有个"读者"回应他，那句被放大成胶卷里的一格
2. **激励写作**：写完整理成一部"小电影"，能「放给他们看」——绘本/动画/漫画

**脊柱理论**：交际语境写作（荣维东）。写作是特定语境中的表达与交流，产品要给孩子
一个**真实的读者**。第二根支柱正是这个读者的落地——所以两根不是并排，是一根给
另一根提供依据。

**技术栈**：React + Vite + Node/Express，JoyCode/OpenAI 兼容模型 API，京东云部署。
不用 TypeScript，不引新技术栈。

**三条红线**（违反即取消资格，优先级高于一切）：
1. 作品内容零个人信息（学校/姓名/指导教师）
2. API Key 不下前端
3. 11-10 24:00 截止，11-07 冻结新功能

## 快速开始

```bash
# 前端（含 mock 数据，不需要后端就能看）
cd client
npm ci
npm run dev          # http://localhost:5173

# 深链：跳过选年级直接进工作台（录屏用）
# http://localhost:5173/?grade=5

# 后端
cd server
npm ci
cp .env.example .env # 填 LLM_API_URL / LLM_API_KEY / LLM_MODEL
npm start            # 没 Key 也能起，/api/chat 返回降级话术

# 评测（9 条离线用例，无 Key 可跑）
cd server && node --no-warnings eval/run.js
```

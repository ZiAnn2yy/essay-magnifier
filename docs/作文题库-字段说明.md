# 作文题库 · 字段说明（给填表的人看）

这份文档说明 `prompts.json` 里每一列是什么意思、怎么填。
**不搞懂字段就填，填出来我没法用。**

填完用下面这条命令转成 JSON：

```bash
node scripts/import-prompts.js <你的csv路径>
```

---

## 一、先决定题库放在哪儿（重要）

题库放在 **`client/src/data/prompts.json`**，由前端直接 import，
不经过后端接口。

理由：题库是几百条结构化事实，总量几十 KB，打进包里比每次请求后端更快也更稳；
演示版是纯静态构建（`vite preview`），不依赖服务器就能跑。
出处靠每条记录自带的 `source` / `sourceDetail` 字段保证，不靠接口。

如果以后题库长到几千条，再改成后端检索——**存储位置换掉即可，
字段和检索函数 `promptStore.js` 不用动。**

---

## 二、CSV 列定义

表头必须正好是下面这 12 列，顺序不限，但列名要一字不差：

| 列名 | 必填 | 取值 | 说明 |
|---|---|---|---|
| `grade` | 是 | 1–6 | 年级。**只收小学 1-6**，初中本期不做 |
| `title` | 是 | 文本 | 作文题目，如 `推荐一个好地方` |
| `form` | 是 | `dahua` / `xizuo` | `dahua`=写话（1-2 年级），`xizuo`=习作（3-6 年级）。**别填错**，它决定提示词的深浅 |
| `type` | 是 | `person` `scene` `object` `event` `imagine` `practical` | 写人 / 写景 / 状物 / 记事 / 想象 / 实用文 |
| `source` | 是 | `textbook` `exam` `ningxia` | 教材单元习作 / 地区考题 / 家乡题材。**见第四节，这三类可信度不同** |
| `sourceDetail` | 是 | 文本 | 具体出处，如 `部编版四年级上册 第一单元习作`。`source=ningxia` 的填 `家乡题材·项目组起草` |
| `status` | 是 | `verified` `draft` | `verified`=已核对可给学生看；`draft`=待审核，**产品里不显示** |
| `hints` | 否 | 文本，用 `\|` 分隔 | 引导问题，如 `这个地方在哪儿\|它有什么特别之处\|你最想让别人知道什么` |
| `payoff` | 否 | `picturebook` `comic` `animation` | 这道题适合变成什么形态，给第二页做默认推荐。可空 |
| `keywords` | 否 | 文本，用 `\|` 分隔 | 这道题可能用到的好词，如 `五颜六色\|生机勃勃\|清香`。**给荧光笔挑词做候选，不填则荧光笔只靠通用词表** |
| `note` | 否 | 文本 | 备注，只给你自己看，产品里不显示 |

### 关于分隔符

`hints` 和 `keywords` 内部用**竖线 `|`** 分隔多个值。
如果某个值里本身要出现竖线，用全角 `｜`。

CSV 本身用逗号分隔列，**所以任何值里出现逗号，一定要用英文双引号把整个值包起来**。
Excel 另存为 CSV 时会自动处理这件事，手写则要自己注意。

## 三、编码（最容易踩的坑）

**CSV 必须是 UTF-8。** Excel 在中文 Windows 上默认可能存成 GBK，
存之前选「CSV UTF-8（逗号分隔）」那一项，不要选「CSV（逗号分隔）」。

导入脚本会做两件事来兜住这个坑：
1. 自动剥掉 UTF-8 BOM（Excel 存 UTF-8 时会带）
2. 如果检测到乱码特征，直接报错并提示你重新另存，**不会静默生成一份乱码题库**

---

## 四、三类来源的可信度不一样（为什么要分 `source`）

| `source` | 可信度 | 谁能填 | 说明 |
|---|---|---|---|
| `textbook` | 最高 | 教师/教研组 | 部编版每单元习作。**权威来源，产品里可对家长出示出处** |
| `exam` | 中 | 教师/教研组 | 地区期末、质检作文题。真实但要标清地区和年份 |
| `ningxia` | 低（本组自编） | 本项目组 | 家乡题材。是为了产品辨识度加的，**不是任何考试的题**，不得冒充教材 |

`status=verified` 只应给 `textbook` 和已核对的 `exam`。
`ningxia` 一律先 `draft`，你确认后才能转 `verified`。

---

## 五、红线（违反即取消参赛资格）

`sourceDetail` 里**只能写到教材单元、地区和年份**。
不得出现：学校名称、学生姓名、指导教师姓名。

- ✅ `部编版四年级上册 第一单元习作`
- ✅ `宁夏某年期末作文题` —— 也不要，写 `地区期末作文题` 即可
- ❌ `XX市第一小学 2025 期末`
- ❌ `李老师给的题`

**地区和年份都不写最安全**，写 `地区期末作文题` 就够用了。

---

## 六、填多少

计划每级 40 条左右，其中教材习作约 16 条（每册 8 个 × 2 册）。
**教材撑不到 40，剩下的靠 `exam` 和 `ningxia` 补。**

少填、填准，比多填、填错好。`status=draft` 的条目产品里根本不显示，
所以拿不准的一律先标 `draft`。
